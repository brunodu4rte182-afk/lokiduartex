# DuarteX Solutions - Landing Page (Loki Project)

An immersive, conversion-focused landing page showcasing DuarteX Solutions' business automation and RevOps services. This project leverages high-performance native web rendering to create a unique, scroll-reactive visual experience without relying on heavy external libraries.

## 🚀 Key Features

* **Scroll-Driven Animation (Canvas 2D):** A smooth sequence of frames (`.webp`) perfectly synced with the user's scroll position, optimized with asynchronous decoding (`decode()`) and smart memory buffer management.
* **Interactive 3D Vortex (Native WebGL):** A dynamic background composed of "threads of time" and particles. Written in pure WebGL with custom shaders, it reacts to mouse movement and scrolling—achieving high performance without the overhead of Three.js.
* **ROI Calculator:** An interactive module estimating hours saved and revenue recovered through process automation.
* **Animated CRM Dashboard:** A real-time visual representation of a sales funnel, featuring dynamic moving cards that simulate lead progression.
* **Extreme Responsiveness:** Dynamic layout adaptation and conditional asset loading (routing to mobile `m/` or desktop `d/` frames) based on the user's device.

## 🛠️ Technologies Used

* **Structure:** HTML5
* **Styling:** CSS3 (Variables, CSS Grid, Flexbox, Modern UI/UX)
* **Logic & Interaction:** JavaScript (Vanilla, ES6+, IntersectionObserver)
* **Graphics Rendering:** WebGL API & Canvas API
